# 减重打卡 · 动态版

基于华山医院减重外科沈其伟主任、心内科包立文教授访谈整理的 BMI>28 中年女性科学减重方案，做成的每日打卡网页应用。

## 功能

- **专属参数计算**：填入身高、体重、年龄、静息心率，自动算出 BMI、基础代谢、每日热量目标、燃脂心率区间
- **每日三件小事打卡**：三餐 211 法则 / 中等强度有氧 30 分钟 / 力量训练或拉伸（连续 3 天没完成自动降级提示）
- **每周测量记录**：体重 + 腰围趋势，重点看腰围
- **数据导出**：每周日晚导出 JSON，交给 AI 生成减重周报与下周建议

## 使用

打开页面即用，数据保存在浏览器本地（localStorage），不会上传。

## 技术说明

- 纯静态 HTML + 原生 JS，无外部依赖、无 CDN
- 数据存储：localStorage
- 发布：GitHub Pages
